分数：$100 + 30 + 50 + 20 = 200$，机房 Rank 2

## T1

这道题其实很简单，但是在考场上卡了我短路的脑子很长时间。

首先，如果把这道题倒过来看，给定一个最大的丑陋值，并求解最多能匹配多少副手套，就变成了经典的 [Codeforces 489B](https://codeforces.com/problemset/problem/489/B)，用双指针扫描两个序列即可。但是这里题目反过来了，再加上“最大值最小”的描述，很容易想到二分法，那我们就把刚才那道题放进 `check` 里就好了。

```cpp
#include <bits/stdc++.h>
#define int long long
const int N = 1e5+10;
int n, m, l[N], r[N];
int Abs(int x) {
  return x >= 0 ? x : -x;
}

bool check(int x) {
  int lp = 1, rp = 1, ans = 0;
  while (lp <= n && rp <= m) {
    if (Abs(l[lp] - r[rp]) <= x) {
      ans++;
      lp++; rp++;
    } else if (l[lp] - r[rp] > x) {
      rp++;
    } else if (r[rp] - l[lp] > x) {
      lp++;
    }
  }
  if (ans >= std::min(n, m)) {
    return true;
  } else return false;
}

signed main() {
  freopen("gloves.in", "r", stdin);
  freopen("gloves.out", "w", stdout);
  std::ios::sync_with_stdio(false); std::cin.tie(0);
  std::cin >> n >> m;
  int minn = 2e9, maxn = 0;
  for (int i = 1; i <= n; i++) {
    std::cin >> l[i];
    minn = std::min(l[i], minn);
    maxn = std::max(l[i], maxn);
  }
  for (int i = 1; i <= m; i++) {
    std::cin >> r[i];
    minn = std::min(r[i], minn);
    maxn = std::max(r[i], maxn);
  }
  std::sort(l+1, l+1+n);
  std::sort(r+1, r+1+m);
  int le = 0, ri = maxn - minn, mid;
  while (le < ri) {
    mid = (le + ri) >> 1;
    if (check(mid)) {
      ri = mid;
    } else le = mid + 1;
  }
  std::cout << ((le + ri) >> 1) << '\n';
  return 0;
}
```

## T2

这道题很容易想到一种解法：

> 首先考虑无解的情况：当有字符出现的次数超过 $\lceil \dfrac{|S|}{2} \rceil$ 时，显然无解，直接输出 `-1` 即可。
> 
> 对于有解的情况，与其考虑如何交换位置，不如我们重新构造一个 `0`、`1`、`2` 数量与原字符串都相等的新字符串，再看看最少的交换次数。
> 
> 观察到 $|S|$ 非常小，允许我们使用状态层数较多的 DP。我们可以设 $\mathrm{dp}(a, b, c, \mathrm{last})$ 表示使用了 $a$ 个 `0`、$b$ 个 `1`、$c$ 个 `2`，且最后一个字符是 $\mathrm{last}$ 时的最小移动距离（当最后一个位置没有字符时，$\mathrm{last} = 3$）。在转移时，我们考虑下一个放置的字符，确保不与前一个字符（$\mathrm{last}$）相同，并将代价加上当前放置位置与原字符串中对应位置的绝对差。那么，我们最终的总移动距离就为
> 
> $$
> \min\limits_{i=0}^{3}\mathrm{dp}(a, b, c, i)
> $$
> 
> 这里需要注意：题目要求的是最少交换次数而非最小移动距离之和，因此要除以 $2$（考虑两个字符交换时，一个字母要从左边挪到右边，另一个要从右边挪到左边，因此移动距离是邻项交换次数的两倍）。
> 
> ```cpp
> #include <bits/stdc++.h> 
> typedef long long ll; 
> const int N = 210; 
> std::vector<int> pos0, pos1, pos2; 
> std::string s; 
> int dp[N][N][N][4]; // dp[i][j][k][last] 表示取了 i 个 0，j 个 1，k 个 2，最后一个字符为 last 时的最小移动步数（交换次数要在这基础上除以 2）。
>  
> int main() { 
>   freopen("string.in", "r", stdin); 
>   //freopen("string.out", "w", stdout); 
>   std::ios::sync_with_stdio(false); std::cin.tie(0); 
>   std::cin >> s; 
>   int n = s.size(); 
>   for (int i = 0; i < n; i++) { 
>     if (s[i] == '0') pos0.push_back(i); 
>     else if (s[i] == '1') pos1.push_back(i); 
>     else if (s[i] == '2') pos2.push_back(i); 
>   } 
>   int cnt0 = pos0.size(), cnt1 = pos1.size(), cnt2 = pos2.size(); 
>   if (cnt0 > (n+1) / 2 || cnt1 > (n+1) / 2 || cnt2 > (n+1) / 2) {
>     std::cout << "-1\n"; 
>     return 0; 
>   } 
>   for (int a = 0; a <= cnt0; a++) { 
>     for (int b = 0; b <= cnt1; b++) { 
>       for (int c = 0; c <= cnt2; c++) { 
>         for (int last = 0; last < 4; last++) { 
>           dp[a][b][c][last] = 1e9; 
>         } 
>       } 
>     }
>   }
>   dp[0][0][0][3] = 0; 
>   for (int a = 0; a <= cnt0; a++) { 
>     for (int b = 0; b <= cnt1; b++) { 
>       for (int c = 0; c <= cnt2; c++) { 
>         int l = a + b + c; // 当前处理到了第 l 位 
>         for (int last = 0; last < 4; last++) {
>           if (dp[a][b][c][last] == 1e9) continue; 
>           if (a < cnt0 && last != 0) { 
>             dp[a+1][b][c][0] = std::min(dp[a+1][b][c][0], dp[a][b][c][last] + std::abs(l - pos0[a])); 
>           } 
>           if (b < cnt1 && last != 1) { 
>             dp[a][b+1][c][1] = std::min(dp[a][b+1][c][1], dp[a][b][c][last] + std::abs(l - pos1[b])); 
>           } 
>           if (c < cnt2 && last != 2) { 
>             dp[a][b][c+1][2] = std::min(dp[a][b][c+1][2], dp[a][b][c][last] + std::abs(l - pos2[c])); 
>           }
>         }
>       } 
>     } 
>   } 
>   int ans = 1e9; 
>   for (int last = 0; last < 3; last++) { 
>     ans = std::min(ans, dp[cnt0][cnt1][cnt2][last]); 
>   } 
>   std::cout << ans / 2 << '\n'; 
>   return 0; 
> }
> ```

输入

```plain
00010020211111221100
```

答案

```plain
16
```

以上程序输出

```plain
15
```

为什么呢？HXF 叽里呱啦说了一大堆，我概述如下：

我们定义一个序列 $a_1, a_2, \cdots , a_n$，表示位于 $i$ 的字符需要与位于 $a_i$ 的字符交换位置。考虑序列 $4, 3, 1, 2$，按照刚才的解法，$\mathrm{ans} = \dfrac{(4-1)+(3-2)+(3-1)+(4-2)}{2} = 4$。然而只需简单手玩即可发现，我们至少需要如下的 $5$ 次变换，才能将其变成 $1, 2, 3, 4$：

$$
4, 3, 1, 2 \\ \downarrow \\
3, 4, 1, 2 \\ \downarrow \\
3, 1, 4, 2 \\ \downarrow \\
1, 3, 4, 2 \\ \downarrow \\
1, 3, 2, 4 \\ \downarrow \\
1, 2, 3, 4
$$

据 HXF 所说，似乎是因为 $1$ 前面有两个数比他大（其实我也不太清楚原理）。

那么正解怎么做呢？首先我们使用数组 $a$ 存储每种颜色的原始位置计算一个前缀和数组 $\mathrm{sum}$，$\mathrm{sum}(i, x)$ 表示前 $i$ 个位置中字符 $x$ 的数量。然后检查是否无解。接着使用 DP 数组 `dp[2][N][N][3]`，其中第一维用于滚动数组优化，第二维和第三维分别表示 `0` 和 `1` 的数量，第四维表示最后放置的字符。初始化数组为无穷大。初始化第一个位置的状态：如果第一个位置为 $x$，成本为 $a(x, 0)-1$。

然后进行动态规划状态转移：从第 $2$ 个位置到第 $n$ 个位置，遍历所有可能的 `0` 数量 $j$ 和 `1` 数量 $k$，并计算黄色数量 $l = i - j - k$。放置 `1` 时，如果 $j > 0$，则从之前状态（最后不是 `1`）转移过来，状态转移方程为

```cpp
dp[i%2][j][k][0] = min(dp[(i-1)%2][j-1][k][1], dp[(i-1)%2][j-1][k][2]) + a[j][0] + max(0, k - sum[a[j][0]][1]) + max(0, l - sum[a[j][0]][2]) - i;
```

另外两种字符同理。在所有位置填充后，输出 `dp[N%2][l1][l2][0]`、`dp[N%2][l1][l2][1]` 和 `dp[N%2][l1][l2][2]` 中的最小值，即最小交换次数。

```cpp
#include <bits/stdc++.h>
const int N = 401;
int n, dp[2][N][N][3], a[N][3], sum[N][3], cnt0, cnt1, cnt2;
std::string s;
int main() {
  freopen("string.in", "r", stdin);
  freopen("string.out", "w", stdout);
  std::cin >> s;
  n = s.size();
  s = " " + s;
  for (int i = 1; i <= n; i++) {
    std::cin >> s[i];
    if (s[i] == '0')
      a[++cnt0][0] = i;
    if (s[i] == '1')
      a[++cnt1][1] = i;
    if (s[i] == '2')
      a[++cnt2][2] = i;
    sum[i][0] = sum[i - 1][0] + (s[i] == '0');
    sum[i][1] = sum[i - 1][1] + (s[i] == '1');
    sum[i][2] = sum[i - 1][2] + (s[i] == '2');
  }
  if (std::max({cnt0, cnt1, cnt2}) > (n + 1) / 2) {
    std::cout << -1;
    return 0;
  }
  memset(dp, 0x3f, sizeof dp);
  dp[1][1][0][0] = a[1][0] - 1;
  dp[1][0][1][1] = a[1][1] - 1;
  dp[1][0][0][2] = a[1][2] - 1;
  for (int i = 2; i <= n; i++) {
    for (int j = 0; j <= cnt0; j++) {
      for (int k = 0; k <= cnt1; k++) {
        int l = i - j - k;
        if (l > cnt2)
          continue;
        if (j)
          dp[i % 2][j][k][0] =
              std::min(dp[(i - 1) % 2][j - 1][k][1], dp[(i - 1) % 2][j - 1][k][2]) +
              a[j][0] + std::max(0, k - sum[a[j][0]][1]) +
              std::max(0, l - sum[a[j][0]][2]) - i;
        if (k)
          dp[i % 2][j][k][1] =
              std::min(dp[(i - 1) % 2][j][k - 1][0], dp[(i - 1) % 2][j][k - 1][2]) +
              a[k][1] + std::max(0, j - sum[a[k][1]][0]) +
              std::max(0, l - sum[a[k][1]][2]) - i;
        if (l)
          dp[i % 2][j][k][2] =
              std::min(dp[(i - 1) % 2][j][k][0], dp[(i - 1) % 2][j][k][1]) +
              a[l][2] + std::max(0, j - sum[a[l][2]][0]) +
              std::max(0, k - sum[a[l][2]][1]) - i;
      }
    }
  }
  std::cout << std::min(
      {dp[n % 2][cnt0][cnt1][0], dp[n % 2][cnt0][cnt1][1], dp[n % 2][cnt0][cnt1][2]});
  return 0;
}
```
