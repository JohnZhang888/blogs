## T1

虽然切了，但是并没有立即证明，只是根据 $n \le 3$ 的特殊性质蒙的。

这道题的结论是：当 $n \ge 6$ 时，最优拆分是尽可能多地使用 $3$，如果余 $1$ 则改用两个 $2$ 代替一个 $1$ 和一个 $3$，如果余 $2$ 则再补一个 $2$。

这一结论可以分为两部分进行证明：

1. 在最优拆分中不会出现 $4$。
  - 假设在最优拆分中存在一个数 $x \ge 4$，那么由于 $x(x - 2) = 2x - 4 \ge x\ (x \ge 4)$，那么将其拆分成 $x$ 和 $x-2$ 更优。如果仍有 $x - 2 \ge 4$，那么仍按照刚才的方法拆分 $x - 2$。因此最优拆分中不会有大于等于 $2$ 的数。
2. 最多只能有两个 $2$。
  - 由于 $3^2 > 2^3$，因此，再最优拆分中，$2$ 的个数不会超过 $2$。如果出现 $3$ 个或更多 $2$，我们可以将其中 $3$ 个 $2$ 替换为 $3$，总和不变，而乘积增大。

对于 $n < 6$ 的情况，打表即可。

:::info[代码]
```cpp
#include <bits/stdc++.h>
using ll = long long;
using ld = long double;
using ull = unsigned long long;
const int INF = 0x3f3f3f3f, _INF = 0xc0c0c0c0;
const ll LLINF = 0x3f3f3f3f3f3f3f3f, _LLINF = 0xc0c0c0c0c0c0c0c0;

namespace IO {
  // 略
} // namespace IO
using IO::err;
using IO::read;
using IO::write;

const int N = 1e5 + 10, MOD = 998244353;
int T; ll n;
int ANS[6] = {0, 1, 2, 3, 4, 6};

ll qpow(ll a, ll b) {
  ll res = 1;
  while (b) {
    if (b & 1) res = res * a % MOD;
    a = a * a % MOD;
    b >>= 1;
  }
  return res;
}

void solve() {
  read(n);
  if (n <= 5) {
    write(ANS[n], '\n');
    return;
  }

  ll cnt = (n + 2) / 3;
  ll cnt2 = 0;
  if (n % 3) cnt2 = 3 - n % 3;
  write((qpow(3, cnt - cnt2) * qpow(2, cnt2)) % MOD, '\n');
}

int main() {
  freopen("first.in", "r", stdin);
  freopen("first.out", "w", stdout);

  read(T);
  while (T--) solve();
  
#ifdef CLOCK
  std::cerr << "\033[95m" << clock() * 1.0 / CLOCKS_PER_SEC << "s\n";
#endif
  return 0;
}
```

## T2

非常小清新的一道 DP。

考虑设 $\mathrm{dp}(i, j, l)$ 表示在前 $i$ 个宝石中进行选择，改变了 $j$ 个宝石的正负性，且选择的宝石能量值之和 $s \bmod m = l$，最多能选择多少宝石。

在处理每一种状态时，分别对不选、选择但不改变正负性和选择并改变正负性三种情况进行转移并取最大值即可。转移方程非常显然，可见代码。

需要特别注意的是要区分值为 $0$ 和不可抵达两种情况。为此可以将不可抵达的状态的值设为 $-1$。

:::info[代码]
```cpp
#include <bits/stdc++.h>
using ll = long long;
using ld = long double;
using ull = unsigned long long;
const int INF = 0x3f3f3f3f, _INF = 0xc0c0c0c0;
const ll LLINF = 0x3f3f3f3f3f3f3f3f, _LLINF = 0xc0c0c0c0c0c0c0c0;

namespace IO {
  // 略
} // namespace IO
using IO::err;
using IO::read;
using IO::write;

const int N = 210;
int dp[2][N][N];
int a[N], n, m, k;
int T;

void solve() {
  read(n, m, k);
  for (int i = 1; i <= n; i++) read(a[i]);

  for (int j = 0; j <= k; j++) {
    for (int l = 0; l < m; l++) {
      dp[0][j][l] = dp[1][j][l] = -1;
    }
  }
  dp[0][0][0] = 0;

  for (int ii = 1, i = 1; ii <= n; i ^= 1, ii++) {
    for (int j = 0; j <= std::min(k, ii); j++) {
      for (int l = 0; l < m; l++) {
        // 不选
        dp[i][j][l] = dp[i^1][j][l];

        // 选且不改变正负性
        if (j < ii) {
          int lastMod = ((l - a[ii]) % m + m) % m;
          if (dp[i^1][j][lastMod] != -1) dp[i][j][l] = std::max(dp[i][j][l], dp[i^1][j][lastMod] + 1);
        }
        
        if (j > 0) {
          // 选且改变正负性
          int lastMod = ((l + a[ii]) % m + m) % m;
          if (dp[i^1][j-1][lastMod] != -1) dp[i][j][l] = std::max(dp[i][j][l], dp[i^1][j-1][lastMod] + 1);
        }
      }
    }
  }

  int ans = -1;
  for (int j = 0; j <= k; j++) ans = std::max(ans, dp[n&1][j][0]);
  write((ans <= 0 ? -1 : ans), '\n');
}

int main() {
  freopen("restart.in", "r", stdin);
  freopen("restart.out", "w", stdout);

  read(T);
  while (T--) solve();

#ifdef CLOCK
  std::cerr << "\033[95m" << clock() * 1.0 / CLOCKS_PER_SEC << "s\n";
#endif
  return 0;
}
```

## T3

一道比较有思维含量的容斥 DP。

设 $S$ 是一个边集，我们令 $F(S)$ 表示强制 $S$ 中的边的两侧没有配对的点的划分方案数。

断开 $S$ 中的所有边后，原树将被划分为若干个连通块。由于 $S$ 中的边的两侧没有配对的点，因此任何两个配对的节点必须位于同一个连通块内，且不同连通块内的点不能配对。

于是，对于一个节点个数为偶数的连通块，其内部必须独立成 **完美匹配**。而对于边集 $S$，$F(S)$ 为其划分出的所有连通块的完美匹配数的乘积，即

$$
F(S) = \prod\limits_{\text{连通块 }B} (\left| B\right| -1)!!
$$

其中 $x!! = x(x-2)(x-4) \cdots 2$（$x$ 是偶数）或 $x!! = x(x-2)(x-4) \cdots 1$（$x$ 是奇数）。

答案为

$$
\sum_{S \subseteq E}{(-1)}^{|S|} F(S).
$$

考虑令 $f(u, i)$ 表示以 $u$ 为根的子树，在已经决定断开某些边（即已选入 $S$）的情况下，当前 $u$ 所在的连通块大小为 $j$，且该连通块尚未封闭，而 $u$ 的子树内其它连通块已经封闭的方案数。

具体地，考虑转移。以下的 $h$ 是临时数组，用于累加合并后的新 $f(u, *)$。初始有 $f(u, 1) = 1$。

- **不断开边 $(u, v)$**：$u$ 和 $v$ 的连通块成为一个更大的连通块，大小相加。有
  \[h(i + j) \gets h(i, j) + f(u, i) \cdot f(v, j).
  \]
- **断开边 $(u, v)$**：$v$ 的连通块成为一个独立的封闭块，需要乘上其内部完美匹配数 $\operatorname{match}(j)$（$j$ 必须是偶数），并乘上 $-1$。$u$ 的连通块大小不变。有
  \[h(i) \gets h(i) - f(u, i) \cdot f(v, j) \cdot \operatorname{match}(j) \ (j \text{ 为偶数})
  \]

根节点处理完后，其所在的连通块尚未封闭，需要乘上内部完美匹配数，得到没有颜色标号的答案。

$$
\mathrm{ans} = \sum\limits_{j \text{（偶数）}} f(1, j) \cdot \operatorname{match}(j).
$$

最后乘以 $\left(\left\lfloor \dfrac{n}{2} \right\rfloor\right)!$ 得到有颜色的答案。

:::info[代码]
```cpp
#include <bits/stdc++.h>
using ll = long long;
using ld = long double;
using ull = unsigned long long;
const int INF = 0x3f3f3f3f, _INF = 0xc0c0c0c0;
const ll LLINF = 0x3f3f3f3f3f3f3f3f, _LLINF = 0xc0c0c0c0c0c0c0c0;

namespace IO {
// 略
} // namespace IO
using IO::err;
using IO::read;
using IO::write;

const int N = 5010, MOD = 1e9+7;

int T, n;
std::vector<int> g[N];
ll f[N][N], h[N];
int siz[N];
ll fac[N];
ll match[N];

void dfs(int u, int pre) {
  siz[u] = f[u][1] = 1;
  for (auto const &v : g[u]) {
    if (v == pre) continue;
    dfs(v, u);
  }
  for (auto const &v : g[u]) {
    if (v == pre) continue;
    memset(h, 0, sizeof(ll) * (siz[u] + siz[v] + 1));
    for (int i = 1; i <= siz[u]; i++) {
      for (int j = 1; j <= siz[v]; j++) {
        h[i + j] = ((h[i + j] + (f[u][i] * f[v][j] % MOD)) % MOD + MOD) % MOD;
        if ((j & 1) == 0) h[i] -= ((f[u][i] * f[v][j] % MOD) % MOD * match[j] % MOD + MOD) % MOD, h[i] = (h[i] % MOD + MOD) % MOD;
      }
    }
    for (int i = 1; i <= siz[u] + siz[v]; i++) {
      f[u][i] = h[i];
    }
    siz[u] += siz[v];
  }
}

void solve() {
  read(n);

  for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) f[i][j] = 0;
  }

  for (int i = 1; i <= n; i++) g[i].clear();
  for (int i = 1; i < n; i++) {
    int u, v;
    read(u, v);
    g[u].push_back(v);
    g[v].push_back(u);
  }

  dfs(1, 0);

  ll ans = 0;
  for (int i = 2; i <= n; i += 2) {
    ans = ((ans + f[1][i] * match[i]) % MOD + MOD) % MOD;
  }

  ans = (ans * fac[n / 2] % MOD + MOD) % MOD;
  write(ans, '\n');
}

int main() {
  freopen("color.in", "r", stdin);
  freopen("color.out", "w", stdout);

  fac[0] = 1;
  for (int i = 1; i <= 5000; i++) {
    fac[i] = fac[i-1] * i % MOD;
  }

  match[2] = 1;
  for (int i = 3; i <= 5000; i += 2) {
    match[i+1] = match[i-1] * i % MOD;
  }

  read(T);
  while (T--) solve();

#ifdef CLOCK
  std::cerr << "\033[95m" << clock() * 1.0 / CLOCKS_PER_SEC << "s\n";
#endif
  return 0;
}
```
