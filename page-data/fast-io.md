以下是我使用的读写模板。其特色在于：

- 简洁统一的 `read()` 和 `write()` 函数语法
  - 使用可变参数实现，用逗号分隔，就可以轻松实现输入 / 输出多个变量。
- 对于 `int`、`long long` 和 `std::string` 类型有快速读入支持
  - 使用 `getchar_unlocked` 实现，可以通过洛谷上的 [快读模板题](https://www.luogu.com.cn/problem/P10815)。
  - 自动检测操作系统，在 Windows 上将 `getchar_unlocked` 替换为 Windows 上可用的 `_getchar_nolock`，方便本地测试。
- 输出和调试有颜色变化

[代码](https://www.luogu.com.cn/paste/z9cfjeq2)

## 使用方式

- `read(a, b, c)`：输入变量 `a`、`b`、`c`。这里的三个参数仅供演示，实际可以输入任意数量、不同类型的变量，支持 `int`、`long long`、`double`、`char`、`std::string` 类型。
- `write(a, b, c)`：输出函数。使用方法和支持的类型与 `read()` 函数相同，但类型多了一个 `const char *`。
- `err(a, b, c)`：输出到标准错误流。使用方法与前两个函数基本相同，但由于使用 `std::cerr` 实现，支持的类型更多。只在加入编译选项 `-DERR` 时显示。
- 在编译选项中加入 `-DCOLOR`，可以使 `write()` 的输出变为蓝色，`err()` 的输出变为红色。
  - 只在部分终端（如 VS Code 终端）生效。在某些不支持的终端（如 CMD），以及输入到文件时会输出乱码。
  - 这一选项会严重影响效率（毕竟多输出了一些东西），建议在测试程序运行速度时关闭。
